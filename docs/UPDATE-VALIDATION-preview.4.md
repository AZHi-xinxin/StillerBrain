## 如何复测

在源码外准备虚拟环境与临时目录。新流程可先运行：

```sh
python -B -m unittest mcp_server.tests.test_person_rewrite_ai_directed
python -B -m unittest tests.test_authoring
python -B -m unittest rikkahub_gateway.tests.test_gateway_unadvertised_feedback
python -B -m unittest discover -s packaging_tests
```

如需全量测试，各组件的发现入口保留在 [上一版复测说明](UPDATE-VALIDATION-preview.3.md#如何复测)。部分选测会占用临时回环端口，适合在空闲开发环境运行。实际使用前刷新 MCP 工具目录，并按当前说明从新的用户轮次继续。
