# 0.2.0 正式版发布检查表

本页对应 `0.2.0` 正式版，沿用 PolyForm Noncommercial 1.0.0。核心版本转正、源码包完整性与各部署路线的扩展验证分开记录；未完成的实验路线不再使整个项目永久标为预览。

## 本版范围

- 保留许可证、贡献、安全、隐私与商业申请说明。
- 新增换源近期记忆、短摘要修复、可选本地语义检索、请求摘要复用及派生连接资料同步；不随源码发布更新已有生产服务。
- 从 preview.7 升级新增四张连续性元数据表，保持原身份、记忆正文、版本和权限；可选语义索引独立存储，默认不启用。
- 核心运行代码与已验收冻结源码一致；Windows 和 Linux 完整核心回归不等于所有手机部署路线的验收。发布检查器正式标识支持另行验证。
- Android／Termux／PRoot／同机 Orbis 全流程、ARM64 Python 与原生依赖实际运行、锁屏常驻及手机备份恢复仍未验收，不能将这些项目勾选为通过。
- 回归、已知限制与实际通过数量见[验证记录](UPDATE-VALIDATION.md)。
- 公开包不包含私人配置、数据库、附件、手机备份或日志。
- 上一版源码状态与验证记录已单独归档，旧结果不冒充新测试。

## 上传前

对最终独立源码目录运行：

```sh
python -B scripts/check_source_package.py
```

核对文件集合、SHA256、实际暂存区、提交内容、远程仓库与标签。源码包完整性不是全历史隐私认证，也不是生产认证。维护者已授权本次发布；变更后仍需重新核对。

本次正式发布已获维护者授权，Orbis 与 Rikka 两端新窗口近期记忆浮现已实测通过。手机路线仍单独标为实验性。源码检查器同时支持历史预览和正式分发标识，两者执行同样的文件与哈希检查。

历史 `scripts/check_release.py` / `release-state.json` 保留更广的通用部署门槛，包括全平台、全依赖与历史内容审计；它不是决定版本名称的工具。其未完成项仍如实保留，不把“正式版”解释为这些项目已经全部通过。具体正式发布证据以 `source-release-state.json` 为准。

## 安装与升级

按[安装](INSTALL.md)或[运维](OPERATIONS.md)操作。升级先结束在途生成与写入，备份全部相关数据库、原配置和图片资料。不要重新生成身份或用示例覆盖现有配置；不要未经核对直接降级旧代码。保留旧源码与升级前备份，恢复数据库前另存当前数据，防止覆盖升级后的新记忆。

新手机独立实例按[手机本地部署指南](PHONE-LOCAL.md)操作；不要直接覆盖已有手机部署，不要在验收前把它作为唯一正式记忆存放位置。iOS、32 位 Android 和没有 Android 运行环境的纯鸿蒙不在此实验路线内。

完整模型目录与宿主运输能力以当前实例为准；新增情绪工具不扩大原权限。仅 MCP 可以主动存查改，自动连带需 ST 网关或等价宿主。

[source-release-state.json](../source-release-state.json) 与 [release-state.json](../release-state.json) 分开；未完成通用门槛保持未完成，不为源码发布改成全部通过。
