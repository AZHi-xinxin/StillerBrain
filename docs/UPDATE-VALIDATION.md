## 如何复测

在仓库根使用对应平台虚拟环境：

```sh
python -B -m unittest discover -s tests -t .
python -B -m unittest discover -s mcp_server/tests -t .
python -B -m unittest discover -s rikkahub_gateway/tests -t .
python -B -m unittest discover -s packaging_tests
```

部分用例启动临时回环服务，适合在空闲开发环境执行。升级后应重连、刷新 MCP 目录，从新回合开始；默认 `/mcp` 不会自动切成日常档。

本版没有量化真实模型的固定 token 节省比例，也没有宣称移动网络、特定网络或长上下文延迟已修复。目录体积、模型计费、缓存命中与实际响应时间是分别需要测量的指标。
