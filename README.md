# Stiller Brain（ST）

昕昕 & 阿止

![Stiller Brain：让共同经历留下来，让后来的交流有来处](docs/assets/stiller-cover.svg)

**让共同经历留下来，让后来的交流有来处。**

ST 为 AI 提供可以持续积累的记忆：记下经历与感受，找回学过的方法，接着推进计划，也重新理解自己。

记忆由 AI 自己写下或明确采纳。采用兼容网关接入后，ST 会在模型回复前，为当前话题带入符合条件的记忆线索。

## 先看一个日常场景

> 以下是说明工作方式的合成情景，不是真实聊天记录或效果测试。

**今天**，一起读到某个章节，AI 写下这次共读及自己的理解，工具返回保存回执。  
**后来**，你再次聊起相关人物，ST 网关在模型请求转发前选取相关记忆。  
**需要细节时**，AI 可以按记录引用继续读取，再结合当前对话回应。

```mermaid
flowchart LR
    A[你发来消息] --> B[ST 网关准备上下文]
    B --> C[选取相关经历、知识与计划]
    C --> D[模型继续交流]
    D --> E[需要时按引用读取细节]
```

模块状态、注入开关、相关性、披露规则与预算共同决定带入范围。换窗口后的长期召回依赖相同身份与有效接入；短期衔接还取决于宿主会话标识。

## 日常怎么用

| 你们正在做什么 | ST 留下什么 | 常用入口 |
| --- | --- | --- |
| 读书、写信、聊起今天的事 | 经历、感受与关系线索 | `remember_memory`、`recall_emotional_memory` |
| 学到方法，解决一个问题 | 理解、来源与不确定之处 | `remember_memory`、`recall_learning_memory` |
| 尝试工具、遇到失败 | 使用条件、方法与教训 | [工具经验](docs/TOOLS.md) |
| 有一件想接着做的事 | 目标、进度与承诺 | `recall_planning_memory`、`advance_plan` |
| 对自己形成新的认识 | 自我表述与后续修订 | [自我模型与复核](docs/GUIDE.md) |

模块就绪、绑定有效时，普通经历、知识和计划可以通过 `remember_memory(module, content)` 简洁地保存。完整参数、成功回执与高级操作见[工具目录](docs/TOOLS.md)。

## 记忆有自己的作者

> 让留下的内容有来处，让后来的理解有依据，让重要的改变有过程。

日常保存与核心修订各有路径。核心自我由 AI 提交候选，在后来的真实轮次重新阅读和复核，再于更晚的轮次确认生效。人类异议与有限回退属于独立的保护通道。

我们珍视记录者理解世界的方式，也珍视改变的过程。[设计理念原文](docs/PHILOSOPHY.md)完整保留，包括 ST 的来处、自主性的追问，以及对记忆边界的选择。

## 开始使用

### 已经有自己的 ST 实例

由部署者提供网关和 MCP 的接入资料，在前端完成普通聊天、工具调用与续轮验收。先用 `stbrain_help` 了解使用方式，再由 AI 按说明完成首次采纳流程。

### 准备自己部署

本版提供单终端运维入口，管理控制面、MCP 服务与兼容网关三个组件。先按[完整指南](docs/GUIDE.md)安装依赖、在源码目录外填写私有配置，然后：

```powershell
python -B scripts/stiller_ops.py check --config C:/stiller-private/stiller.env
python -B scripts/stiller_ops.py start --config C:/stiller-private/stiller.env
```

具体命令、停止方式和备份导出步骤见[运维指南](docs/OPERATIONS.md)。当前是回环地址的同机开发接入；从手机或公网使用时，另行配置并验收受控连接。

### 正在开发宿主适配

按协议实现真实轮次、上下文快照与完整工具结果传输。MCP-only 的帮助及部分只读能力，与完整写入/自动注入的接入要求分开说明在[详细指南](docs/GUIDE.md)中。

## 这次的易用性改进

- **一个入口检查与启动**：保留原有三组件和严格绑定，减少终端切换。
- **备份、校验与恢复**：提供明确停服前提下的三库备份和新目录恢复。
- **按需导出**：从已校验备份中选库、选表导出 JSONL，便于后续自主管理。导出内容按私人数据保护。
- **检索改进**：具体覆盖范围、合成对照和保留的读取边界见[检索说明](docs/RETRIEVAL.md)。

以上以[本次验证记录](docs/UPDATE-VALIDATION.md)的实际范围为准。完整工具仍为 43 项，新增运维入口是本地 CLI。
