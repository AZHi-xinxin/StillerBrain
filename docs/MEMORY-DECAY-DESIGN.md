# 记忆渐隐：设计讨论稿

状态：**仅设计，尚未实现。** 本预览版的代码改进不包含普通记忆渐隐算法。

## 产品目标

让不常相关的普通记忆逐渐减少日常占位，保留原文、来源、作者赋予的重要度和明确读取路径。核心自我、常驻提醒、有效承诺分别沿用各自规则。

区分三个含义：

- **重要度**：记录者对内容价值的判断，保留理由与版本。
- **活跃度**：普通记忆进入日常自动上下文的优先级，可随时间变化。
- **相关性**：与当前问题的匹配线索。分数是排序信号，并非“理解了多少”的概率。

现有情感记忆已经对关系边做时间衰减；这与拟议中的普通条目渐隐是不同机制。

## 讨论后的取舍

| 建议 | 设计取舍 |
| --- | --- |
| 扫描与使用分开 | 采纳。自动注入、扫描、重试等不直接产生强化 |
| 无工具操作就视为忽略 | 不采用。正确且重要的背景可能被安静地使用，“没修改”不足以判定无用 |
| 相关分数超过 70% 即保护或回升 | 改为待验证的相关性证据；绝对阈值和相对最高分都不能独立证明有效使用 |
| 高频命中自动晋升常驻 | 常驻继续由 AI 显式选择并遵守配额；频率只能形成候选依据 |
| 读时计算、少量异步记事件 | 采纳方向。避免每次唤醒逐条改写权重，事件自身也要有容量和去重策略 |
| 常驻/冷却状态加迟滞 | 采纳到设计。稳定观察窗口、最短停留期和不同进出条件共同防抖，保持作者最终选择 |
| 标签带原记录引用 | 采纳。作者写的摘要/标签与可解析的 ID、版本及读取方法一起保留 |
| 关键词命中就强制输出原文 | 改为保留准确查找能力；命中不扩大敏感内容的披露权限 |
| 自动压缩旧摘要 | 延后。首版只改变排序；新摘要若进入后续版本，需保留来源、作者采纳与修订流程 |

“不操作”和“未被理解”之间没有可直接观测的等号。高相关命中可以作为**暂缓降权的有限证据**，但无限自我强化会让经常被挑中的条目永久占据上下文。候选策略需要设置保护期限、每窗口上限和去重，保留对不常提及的旧经历的检索能力。

## 相关性的三个陷阱

1. 当前公开实现以确定性文本线索为主，不能把词法分数当成 embedding 概率。
2. 相对阈值 `本条 >= 0.7 × 本轮最高分` 仍可能在全是低质量结果时把噪声评为有效；Top-K 总会有第一名。
3. 查询中已经含有之前注入的摘要时，再用该查询证明“独立有效命中”会产生循环。候选证据应来自可信的新用户意图或任务事件，并与注入内容隔离。

后续实验需要结合最低质量条件、精确实体线索、排名差距、独立窗口与作者确认，分别记录不确定性。没有经验证的阈值，先不给默认参数。

## 候选计算与时间证据

试验公式可从 `floor + (1-floor) × 2^(-elapsed_days / half_life_days)` 开始。它是一种工程候选，不是已验证的人类记忆拟合。

- 参数为有限值，`floor` 在 0–1、半衰期大于 0；非法值恢复原排序。
- 经历发生时间、元数据更新时间和真正的使用时间分开；导入旧经历提供明确宽限期。
- 读时计算只派生活跃度，不修改原始重要度或内容版本。
- 高频日志去重并限额；关键使用事件先可靠落地后才用于强化，失败时不返回已强化。
- 只有可信且独立的事件才能作为有限证据。模型自述“我用到了”与单纯重复读工具都不足以无限提权。
- 同一真实唤醒轮次固定时间和快照；跨轮次才重新判断，保持缓存和重试稳定。

## 接线边界

先按原有身份、生命周期、模块开关与内容策略确定资格，再按原始相关性决定允许呈现的摘要/原文，最后用旁路活跃度对相关度相近的普通候选排序。

保留原 `score` 的语义，避免渐隐碰到原文披露门槛。混合选择器会重新排序，也有候选提前截断；实验需要覆盖最终选择效果和候选池范围。常驻、有效计划紧迫度、精确读取和总预算继续遵守原规则。

已有 `build_injection` 会清理过期短期内容并写审计。设计实验采用纯函数与合成投影，避免把它当成生产库的无副作用读取接口。

## 分阶段验收

1. 纯函数合成数据：同相关度时间变化、无关高频扫描、重要但无需操作的稳定背景、全低分查询、缺失/未来时间、旧记录导入。
2. 权限与可追溯：敏感内容、never_auto、关闭模块、跨身份事件、原文与版本、精确引用读取全部保持边界。
3. 稳定性：重复事件幂等、状态迟滞、事件写入失败、停留窗口、同轮次快照、候选池截断和预算。
4. 独立实例：比较无关占位、相关召回、旧事找回、延迟与 token，再决定参数。
5. 真实实例试用须另行确定范围、备份、关闭开关和回退验收。

当前版本只保存本设计，没有定时衰减任务、条目自动归档或重要度迁移。
