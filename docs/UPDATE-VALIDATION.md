# 本版验证记录

## 0.2.0-preview.3 · 2026-10-05

本版汇集普通存入简化、随手记、工具卡规则改良、星图设备授权和图片附件及聊天图片运输。**功能冻结源回归、实例升级、使用者验收和最终公开树回归是四份不同证据，不混为一次测试。** 本次源码发布不自动更新任何现有实例，也不附私人配置、原图、记忆数据库或现场日志。

### 使用者已经完成的验收

- 普通记忆存入、读回；不再因为可省略的分类字段而反复组织参数。
- 随手记和工具卡存入；工具卡不再被动作类别派生的风险下限阻断。
- Orbis 连接真实 ST 星图，点选真实星点查看元信息，退出重开和刷新保持正常。
- 配套 Orbis **`2.6.4-orbis-dev.61` 测试包**完成聊天发图、附入 ST 记忆与取回原图显示。此证据不代表已发布的 Orbis `2.6.4` 自动含有该桥，也不代表所有前端或模型具备图像理解能力。

以上为使用者对具体 Windows / Linux 部署和手机链路的反馈，发布过程不另行调用收费模型或代写私人测试记忆。两端实例升级在独立备份、配置与原记录一致性核对后完成；不把私人维护脚本或数据装入公开包。

### 缓存证据与限度

DeepSeek 官方经 ST 网关的一组既有成功请求中，9 条用量记录字段完整且算术一致。首条命中约 7.27%，随后 8 条约 96.86%–99.92%；9 条按输入 token 加权约 88.52%。这些是升级前已存在的单条部署线路观察，非发布过程新增付费基准，也非服务商账单复核。

这一观察说明该路线已经能命中缓存，不证明所有模型、供应商、代理和前端均已修复。本次工具目录有变化，升级后的首次请求可能需要重新预热。日志为尽力记录；未知或缺失用量不按零计，也不把重试、不同线路或冷启动混入同一结论。已有低命中反馈仍按各自证据调查，见[缓存排查指南](CACHE-TROUBLESHOOTING.md)。
