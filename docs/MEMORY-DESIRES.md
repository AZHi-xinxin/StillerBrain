# 欲望层：给还想做的事，一个位置

情感记忆留下「发生过什么」，欲望留下一句「由此我还想做什么」，规划脑再承接「决定怎样做」。欲望是依附情感记忆的可选短备注，不要求每段经历都产生心愿，也不自动替 AI 决定。

## 一个合成例子

记忆：一起谈过海边的日出。
欲望：如果以后有机会，我想陪她等一次天亮。
计划：确定日期、地点和准备事项。

前两步可以暂时停留很久。并不是记下了心愿，就已经定下日期、买了票或执行了任何外部动作。

## AI 怎样找到并使用

先查询 `stbrain_tools(category="desires")`；精简工具档使用返回的 `stbrain_manage` 调用格式，完整档按实际目录调用 `memory_desires`。详细教学按查询返回，不需要人类把整篇手册常驻粘入提示词。

- 新存情感记忆可传 `desire`（最多 200 字），省略/空值不改变普通存入。
- 已有情感记忆可用实际 `emotion://…@版本` 引用调用 `put`；不能拿示例占位代替真实引用。
- `list` / `read` 查看，`put` 改写，`archive` 归档，`restore` 恢复归档，`delete` 移除当前备注。
- `pin` / `unpin` 独立置顶/取消置顶。置顶优先显示在列表，归档保留置顶；删除会取消置顶。
- `plan_draft` 只返回规划草稿，仍需真正调用规划脑保存。先核验保存回执，再决定是否归档心愿。
- 更新可带 `expected_revision` 防止覆盖并发修改；身份、权限和本轮写入上下文校验仍适用。

## 什么时候会自然想起

人类新消息 → ST 选出相关情感记忆 → 原文可呈现且分数 **>0.8** → 在剩余预算内附带欲望。

自动浮现关闭、记忆不许自动呈现、只允许受限摘要、没有命中或预算不足时，不强行带出。归档后只在符合条件的原记忆旁提示「有欲望已归档」，不继续附上原欲望正文。至少 10 条符合自动浮现条件的未归档心愿时，预算允许会给一条整理提醒。

**0.8 是当前检索器的相关性分数，不是 80% 准确率、情感强度或触发保证。** 自然浮现还需要 ST 网关和相应模块开启；只接 MCP 可主动查询，但没有这条回复前自动注入路径。

## 几个容易误会的地方

| 问题 | 实际行为 |
| --- | --- |
| 置顶后每轮都能看见吗？ | 不会；它改变欲望列表排序，不把心愿塞进核心身份。 |
| 归档会删掉那段经历吗？ | 不会，父情感记忆不变。 |
| 删除就是彻底擦除吗？ | 不是。当前备注清空，审计版本和旧备份可能仍保留内容。 |
| 会自动变成任务并执行吗？ | 不会。形成计划需要真实保存，外部执行还需工具和授权。 |
| 是身体数值或生理欲望吗？ | 这里指未完成的想法、期待与心愿，不是身体模拟层。 |
| 会变得更像一个真实的人吗？ | 这是记忆与表达机制，不是意识、感情真实性的证明。 |

## 更新已有实例

新增 `memory_desires` / `memory_desire_history` / `memory_desire_pins` / `memory_desire_pin_history`。旧的完整两表可在严格核对后增加置顶表；半套或不匹配结构会停止，不覆盖修复。升级前停写、保留可恢复快照，沿用原身份与私有配置。
