本版发布已验收的情绪层、安装运维诊断与网关修复。维护者已确认 Orbis、Windows ST 与 VPS ST 配套测试通过；这不等同于所有客户端、模型、网络和全新机器都通过。

公开树的 296 个 Python 文件与已部署验收的情绪层候选包逐字节相同。本轮新增设计理念、使用说明、AI 内置帮助指引与发布资料；没有再次部署生产服务，没有调用真实模型或访问私人记忆。历史验证见[上一版记录](UPDATE-VALIDATION-0.2.0-preview.4.md)。

### 本轮隔离回归

本轮对公开 Python 树重新运行运行时、MCP、网关、安装包装和迁移五组测试。凭据环境剥离，临时库独立，网络只允许回环并拒绝已知生产端口；显式启用 35 秒真实回环长流。测试环境是现有隔离 Python 环境，不是空白机器安装。

本轮共运行 2,500 项：2,498 项通过，2 项平台相关跳过，0 失败、0 错误。五组均确认执行前后源码未变化。

### 新功能的验证边界

- 情绪词表自由增删改、归档恢复、默认占位不重建；删除词条不删记忆。
- 新保存与标签事务一致，旧记录引用及版本检查，所有者和模型隔离。
- 主命中优先、定义及连带共用预算、0–3 条与冷却、同一唤醒工具续轮不重复计数。
- 暂停、隔离、未授权及主动读取模块不借标签绕过；工具目录与图片运输能力分开。
- 安装与运维状态诊断、长流及工具尾部处理、明确思考参数兼容保留回归。

### 发布审查与限制

新增数据库表和索引，因此升级前必须停写、备份，保留原身份与配置；不能把上一版“无数据库结构变化”照搬到本版。参见[情绪层](EMOTION-LAYER.md)与[运维](OPERATIONS.md)。

公开集合排除数据库、真实附件、日志、私有配置及现场备份。四处新增凭证模式命中均为独立测试环境中的明确合成字符串；不能拿它们连接真实服务。最终文件集合与哈希由 `SOURCE-PACKAGE-MANIFEST.json` 校验，实际 Git 归档另行核对。

本轮完整回归平台为 Windows；既有 Linux/VPS 配套验收不冒充本轮公开树的全量 Linux 重跑。普通记忆迁移前端真实迁移、咨询室完整流程、全新机器安装、全依赖实时安全审计及全 Git 历史隐私认证仍是独立范围；OB 直读批量迁移和银河视觉重构未实现。没有进行新的付费缓存基准，不承诺所有供应商缓存命中率。
