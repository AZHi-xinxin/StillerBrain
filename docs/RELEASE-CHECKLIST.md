## 每次上传前核对

以最终准备上传的目录为对象运行：

```sh
python -B scripts/check_source_package.py
```

检查最终文件集合和 SHA256，排除配置、数据库、附件原图、备份、现场日志及凭证。源码清单更新后若有修改，必须重新核对。该检查不是全 Git 历史的隐私审计、法律意见或生产认证。

使用 Git 提交时另核对实际暂存区、提交历史及远程目标。通过源码检查、得到发布授权、真正上传 GitHub 是三个分别记录的步骤；本检查表不授权自动提交或部署。
