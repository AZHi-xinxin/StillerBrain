- **Windows 权限**：在新 NTFS 目录上设置受保护的访问列表，核对目录和配置文件仅有当前用户与 SYSTEM 的访问规则；随后建立的文件继承该私有目录权限。
- **自动测试**：新增 47 项安装契约测试，与原包装/运维测试一起执行，共 117 项；116 项通过，1 项 POSIX 文件模式测试在 Windows 上跳过。包括真实三服务选测、路径与链接保护、隐藏输入、平台预检、原配置保留、失败重跑、端口占用和不发模型请求。

安装检查验证本机软件条件；真实模型密钥、客户端兼容、远程手机连接、后台常驻、长期使用与升级迁移仍分别验证。向导创建新的空白实例，不替使用它的 AI填写自我定义。

## 如何复测

先建立源码外的虚拟环境和临时目录，并为所有子进程设置 `PYTHONDONTWRITEBYTECODE=1`：

```powershell
$env:PYTHONDONTWRITEBYTECODE = '1'
python -B -m unittest discover -s tests -q
python -B -m unittest discover -s mcp_server/tests -q
$env:STBRAIN_LONG_STREAM_TEST = '1'
python -B -m unittest discover -s rikkahub_gateway/tests -q
$env:STBRAIN_RUN_LOCAL_SERVICE_SMOKE = '1'
python -B -m unittest discover -s packaging_tests -q
```

选测会真实占用临时回环端口，并使用合成上游；请在空闲的开发环境运行。配置与备份步骤见 [GUIDE](GUIDE.md) 和 [OPERATIONS](OPERATIONS.md)。
