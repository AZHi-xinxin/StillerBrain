# 本机普通记忆迁移（实验 MVP，真实迁移验收暂缓）

这是独立的本机前端，不是新的 ST 核心权限入口。它读取用户选定的旧档案，由用户配置的模型分类，然后仅调用认证 ST 的两个固定写接口。**本目录的合成测试不等于真实源服务、付费模型和目标 ST 已验收。**

`0.2.0-preview.3` 保留这份实验代码供审查与隔离测试，尚未完成真实来源到目标的完整界面验收。**OB 地址直读、由 AI 精选条目或全量一键搬运未实现，后续开发暂缓。** 本版普通保存、随手记、图片与星图通过，不表示旧记忆迁移也已通过。

## 启动

使用已安装本仓库依赖的 Python 环境，从仓库根运行：

```text
python -m migration_ui.server
```

终端只显示 `http://127.0.0.1:<随机端口>/`，在本机浏览器打开。可用 `--port 具体端口` 固定端口。不会绑定公网或局域网接口，不要使用反向代理公开此页面。

默认私有数据目录：Windows `%LOCALAPPDATA%/StillerBrain/migration-ui`；其他系统 `~/.local/share/StillerBrain/migration-ui`。可用 `--data-dir` 指定专用目录，但最后一级必须为 `migration-ui`，不得传工作区或现有业务数据根。Windows 新目录只允许当前用户、SYSTEM、Administrators；重开时校验现有 ACL。POSIX 目录 0700、文件 0600；拒绝链接与未知文件。原始档案可能很私密，磁盘应启用自己的系统加密。目录不在仓库内，不应提交 Git。

按 Ctrl+C 停止后续条目；在途请求会等待当前有上限的网络请求结束。强行杀进程后，账本中“发送中”的条目下次一律变为 UNKNOWN，不重新发送。

## 三组配置

1. **来源**：UTF-8 JSON / Markdown 文件，最大 4 MiB；或用户明确指定的只读 GET 导出 URL，可填写独立 Bearer 凭证或留空。JSON 支持顶层数组，或 `{"memories":[...]}` / `{"records":[...]}`；项为字符串，或具有指定纯文本字段的对象。正文字段默认 `content`，可改为 `text` / 中文字段。未知结构明确拒绝，不递归搜集任意私密配置。完整文件保留；非正文字段、附件、关系不自动写入 ST。
2. **分类模型**：兼容 OpenAI Chat Completions 的完整端点、实际模型 ID、可选密钥、补充分类提示词。仅使用普通非流式消息，不提供 tools/function calling。模型可能计费；先看总片段数和内容流向。
3. **目标 ST**：认证 `/mcp` 完整端点、目标密钥、稳定的目标记忆库名称。目标须已经启用 `simple-memory-v1`，模块一须已正常激活。连接检查只初始化 MCP、读取工具目录，不读取 self、不激活任何模块。

公开服务使用 HTTPS；本机 `localhost`、`127.0.0.1`、`::1` 可用 HTTP。其他 HTTP 地址需在对应来源／模型／目标一栏单独勾选知情许可，而且只接受 RFC1918、`100.64.0.0/10`（如 Tailscale）、IPv6 ULA 的 IP 字面量；不接受公共 IP、link-local 元数据地址，不能靠 DNS 解析升级为受信内网。**HTTP 本身不加密**，VPN 安全性另由自己的网络保证。不跟随重定向、不继承环境代理。分类与 ST 地址不支持查询参数、URL 内凭证或 fragment。来源 GET 可有普通分页/导出查询参数，但不要把密钥放 URL，使用独立凭证字段。

**尚无已实现的 OB 直连适配**：这里只支持上述通用导出，不虚构 OB MCP 工具、私密源遍历或自动分页协议。源地址必须是实际导出地址，不能填写管理首页或任意 MCP 地址期待本工具自行探查。

## 写入与内容完整性

用户确认“旧档案 → 指定模型 → 指定 ST”后，可一键分析、校验和串行写入：

| 内容 | 固定接口 | 边界 |
| --- | --- | --- |
| 情感 / 学习 / 规划 | `remember_memory` 对应 module | 原文来自不可变本地片段，最多 2,000 字，不采用模型改写正文；外部来源 reported；不编造已验证来源 |
| 工具 / MCP 服务说明 | `remember_tool_guidance` | 只有原文里明确出现的工具名；提交完整原片段到 call_notes，超过 800 字进入待处理；ST 工具卡既有规则会去首尾空白，逐字节原件以本机保存为准；迁移器使用 medium/none 默认值，不是已核验的风险判断，也不授予或执行真实工具操作 |
| 其他 / 不明确 / 校验失败 | 不写入 | 原文件保留，显示待处理原因，不强塞进其他类别 |

长文按原始字符位置分段，优先换行，来源 SHA-256、记录序号、字符偏移和片段 ID 写入来源说明。原始时间不改成迁移时间，不伪造源身份；本版结构化时间 / 关系 / 旧 ID 不另作字段映射。保存 title/summary 等模型整理字段不代表原文被删除。

分类器不能选择任意工具、目标地址或认证字段。self、治理、注入开关、授权、修订旧记录、关系写入等均不在白名单。工具卡只新增；同名 operation 冲突进入“明确拒绝”，不覆盖旧卡。工具使用说明是数据，不是后续真实执行授权。

源片段会做确定性的疑似凭证检查和本轮密钥精确值检查；这是启发式防护，不保证能识别任意秘密。用户仍需在导出前检查资料。界面配置密钥、提示词不写日志或磁盘；原始导出和短回执留在私有目录。

## 中断、去重与 UNKNOWN

账本在每次目标请求之前耐久写入 SENDING，得到完整成功回执后才记 STORED；成功项下次跳过。明确 `reject + state_changed=false` 才记拒绝。断线、超时、未知/错误格式回执、发送后进程中断都记 UNKNOWN 并停止，不自动重放。

**这不是 exactly-once，也不能凭查询不到证明没写入。** 现有情感/学习 API 每次新建 ID，通用迁移没有目标端幂等请求 ID。UNKNOWN 必须人工核对；工具没有“强制忽略 UNKNOWN”的按钮。原件和账本一起保留。

本机去重键包含“目标端点＋用户填写的目标库名称＋原文件 SHA＋格式/正文字段映射＋片段位置及内容哈希”。同一库续传必须使用同一名称与原文件及映射；更改文件字节、映射、端点或名称会形成不同来源/目标，可能重复迁移。端点改属另一个用户时必须换名称，不能复用旧成功账本。不会持久化密钥或密钥摘要作为目标身份。未来若需要可靠跨地址续传，应增加服务端原子迁移回执协议，而不是放宽未知结果重试。

取消只阻止后续片段，不撤销已保存内容；在途写若成功仍记录成功。关闭浏览器不取消服务器任务，先按“停止后续条目”。网络请求无自动重试；状态页面轮询仅为本机只读。

## 本地验证

```text
python -m unittest discover -s migration_ui/tests -v
```

测试只用合成资料、临时私有目录、mock 分类器 / MCP 以及本机 HTTP 服务器；不会读取真实配置、访问真实私密源、调用收费模型或写生产 ST。真实连接的端到端体验需用户另行提供测试项目并明确授权后验收。

另有可选 `node migration_ui/tests/browser-smoke.cjs <Python路径> [合成截图输出路径]`，需要测试环境已有 Playwright 和浏览器；不会自动下载依赖。可设置 `MIGRATION_BROWSER_CHANNEL=msedge` 使用现有 Edge 的独立无账号临时浏览器。此脚本只启动临时合成服务、上传合成文字，拦截非本机网页请求，不连接真实目标。

当前 MCP 客户端明确支持本仓库的 stateless HTTP + JSON 响应协议（2025-03-26），不是任意 SSE / 有状态 MCP 客户端。未知版本、分页工具目录、要求旧 write_context_ref 的服务会拒绝，不降级认证。
