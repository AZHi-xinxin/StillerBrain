# 日常记忆：想留下的话，直接存

这是 `0.2.0-preview.3` 的日常入口说明；是否可用以所连接实例的工具目录和版本为准。ST 是可选工具，不要求模型在所有场景优先使用它，也不保证每条记录都会自动出现在后续对话里。

## 两种用途，都只需正文

日常回忆、经验或计划，用现有 `remember_memory`：

```json
{"content":"今天一起把那段旧故事讲完了，我想记住这份踏实。"}
```

临时想法、工作碎片或尚未整理的笔记，用现有 `remember_work_memory`：

```json
{"content":"下次整理界面时，再看看按钮旁的那段说明。"}
```

第二种是**随手记**：原文存在 ST 的独立工作记录里，标签省略时为“随手记”。它不自动混入长期回忆、日常网关注入、普通混合检索或星图；不自动整理、转存或额外调用模型。需要读或整理时再显式查询、修改。

`simple-memory-v1` 完成首次激活后，两者均无需为了日常存入先查目录或调用 `stbrain_open`；旧模式仍保留原有真实授权上下文。现有 `daily` 目录展示 8 个入口，增加的是已有随手记工具的可见性，没有注册第二个重复存入工具；`full` 目录保持原有工具集合。

## 默认值是省步骤，不是替你编故事

`remember_memory` 的 `content` 是唯一必填字段，1–2000 字，正文原样保存，不静默截断或改写。

- `module` 默认 `auto`；省略、`null` 或空字符串均可。没有明确分类线索时存到情感记忆，类型为 `unclassified`，并不把片段判成“重要对话”。
- 自动选择只看明确元数据：计划父项、截止时间或计划类型会指向规划，学习类型会指向学习。**不靠另一模型阅读正文做语义分类**。有明确用途时仍可直接填 `emotional_memory`、`learning_memory` 或 `planning_memory`。
- `kind` 可省略、留空或 `null`；`moment`、`event` 可兼容为事件。非标准日常分类不会只因名称不在枚举中就丢掉正文；系统使用保守默认，并在回执给出提示。
- `emotion` 可省略、留空或 `null`；默认 `other`，不猜作者的情绪。不能识别的感受也保守归类并提示。
- `importance` 可省略、留空或 `null`，默认 50；可明确填写 0–100 整数、数字字符串或整数值小数。布尔值和越界评分仍拒绝。
- `keywords` 可不填、为空或 `null`；也可给短语数组或兼容字符串。无需为了一次存入临时编一组标签。
- 来源未填为 `unmarked`，可信度未填为 `null`；不会假装已经核验。标题和摘要未填时仅从原文派生短展示字段，不改原文。

例如下面仍是一次普通存入，不需要再开一轮确认：

```json
{"content":"我记得这次一起解决问题的时刻。","kind":"moment","importance":null,"keywords":[]}
```

自动整理不改变权限：未知模块名不会被映射到自我定义、工具治理或其他更高权限模块。回执中的实际 `module`、引用和 `input_warnings` 固定提示可以用来核对归档位置。

## 需要时再找回、整理

日常记忆查询：`stbrain_open(view="recall", query="想找的片段")`；不填查询词可分页浏览。按返回的精确引用读取原文，修改使用已读到的当前版本引用；遇到版本冲突先重读，不自动覆盖。

随手记的读取示例（`daily` 目录）：

```json
{"action":"recall_work_memory","arguments":{"query":"随手记"}}
```

将以上参数交给 `stbrain_manage`。标签查询是字面匹配，不是语义搜索；空 `query` 可显式分页浏览。按返回的 `target_ref` 调用 `revise_work_memory`，修改正文或标签，历史版本保留。

## 哪些边界照旧

- `simple-memory-v1` 仍须先完成模块一的首次激活；激活前可查询但不能存入。完成后普通直连与网关无需人类反复确认每条普通记忆，也不用自己填写内部上下文或模块行版本。
- 旧授权模式仍需要原有真实上下文；本说明不代表任意旧部署都已免除其前置授权。网关的 `execution_ref` 由宿主绑定，模型不能编造、挪用或重放。
- 已明确确认的 `rewrite_receipt` 保留精确字段匹配，不能借“自动补全”改变已确认内容。它是特殊可选路径，不是普通存入必经步骤。
- 计划只是记录，不代为执行外部操作；随手记沿用学习脑授权，不新增外部工具权限。凭据与密钥仍不能存入。
- 只有真实 `stored` 回执才表示成功。拒绝、连接中断或未知结果都不应说“已记住”；未知结果先查再决定，不自动重复提交。
- 随手记正文上限为 32768 字符且 UTF-8 不超过 128 KiB；更大的内容使用适合的附件入口，不要默默截断。

普通存入和随手记已在具体部署完成使用者验收，范围见[验证记录](UPDATE-VALIDATION.md)。下载源码不自动升级已有实例，也不改动任何已有数据库。
