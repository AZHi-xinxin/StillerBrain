# 关键词必浮现

这是普通四脑的可选召回优先项，默认关闭，由所属 AI 开关。它只改变浮现优先级，不改写原记忆、重要度、衰减或原有披露设置。四脑合计最多开启 10 条；第 11 条明确拒绝，需要先关闭一条，不会自动替换。

精简目录仍为 8 个入口。通过 `stbrain_tools(category="force_recall")` 或 `stbrain_tools(action="memory_force_recall")` 获取操作说明；用 `stbrain_manage(action="memory_force_recall", arguments={...})` 执行。

- `action="enable"` / `"disable"`：提供当前版本的 `target_ref`，例如 `emotion://记录ID@1`。可传 `expected_revision` 检查这个开关自己的修订号；初次是 0。记忆内容版本与开关修订号不同。
- `action="read"`：按引用查看开关、命中次数、实际注入次数、最近时间和未注入原因。
- `action="list"`：查看当前开启项与剩余名额。
- `action="guide"`：查看语义说明。

只支持 `emotion://`、`learning://`、`plan://`、`tool-card://`。模块一、黑匣子、工作随手记不参与。没有增加人类写入开关的接口；元数据与回执可以作为只读结果查看。未接通网关注入的纯 MCP 使用不会自动产生命中。

匹配只看本轮最新的人类正文；中文按已保存词句，其他文本按词边界，不区分大小写并兼容全角字符。`ex`、`我说EX那件事` 可命中，`example`、`text` 不会因其中两字母触发必浮现。普通语义召回仍有自己的候选机制。旧历史、AI 回复、工具结果、哨兵和工具续轮不作为新的关键词命中。

命中项在普通动态候选之前占用既有共享预算，常驻计划提醒仍保留。只投影原作者的简短摘要或获准的存在提示，不展开私人正文。多个命中时先保留本轮最后明确提到的一项，其余按重要度；摘要过长标明摘录，放不下的项显示省略数量。若宿主基本上下文已占满到连最小提示也放不下，诊断明确记为未注入，不超出硬预算或伪报成功。完整内容仍按原引用与权限查询。

关闭总浮现时不扫描；模块关闭、隔离、禁召、先询问和语境限制仍优先。工具记忆只是历史参考，不能当作执行授权。学习与情感记录的来源、可信度和披露说明继续保留在具体查询的工具返回里，日常浮现使用短摘要与编号。

`hit_count` 是所属宿主已经确认上下文的唯一新人类事件数；`injected_count` 只统计实际包含该项的已确认快照。预览不计数，失败准备不计数，同一事件重试与工具续轮不重复计数。两者都不证明模型已理解内容或答对。计数与开关历史旁路保存，不影响原记忆正文。
